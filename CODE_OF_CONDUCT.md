# Code of conduct

This project adopts the [Contributor Covenant 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/) as its code of conduct. It applies in the repository's issues, pull requests, reviews and comments, and wherever someone represents the project.

## Reporting

Report a possible violation privately to the maintainer, @ChristianPrzybulinski: open the repository's **Security** tab → **Report a vulnerability** and start the title with `Conduct:`. Only the maintainer and you see the report. Say what happened, where (a link) and when, and keep personal data to what the report needs.

The maintainer is the project's only moderator. They handle a report as the Covenant's "Addressing and Repairing Harm" section describes and keep it private. A report about the maintainer goes to GitHub instead, through [Reporting abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
