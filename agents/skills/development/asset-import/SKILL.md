# Asset Import

Four areas, never mixed: **originals** (read-only) → **normalized** (standardized format/name, no interpretation) → **derived** (transparency, atlas, crops — decisions recorded) → **imported** (what Godot reads, `res://`). Everything that leaves a stage has a manifest pointing to the previous stage.

## 1. Before the batch

- Read the project's binaries rule (`agents/rules/git/git-lfs-and-binaries.md`, `.gitattributes`): what goes to LFS, what stays out of the repo.
- Read `docs/legacy/` (or equivalent) for already-known archive gaps: divergent pairs, missing members, unresolved transparency. Do not assume completeness.
- Confirm the originals' hashes against the origin manifest. Divergence → stop and report.

## 2. Manifest (one per batch, stable format — CSV or JSON)

Minimum columns: `origin_path, origin_sha256, cast, number, name, aliases, width, height, pivot_x, pivot_y, origin_format, derived_path, derived_sha256, transformations, status(ok|rejected|review), reason`.

- Duplicates by hash: one derivative, all aliases preserved on the same row.
- Pairs that diverge (e.g.: PNG≠BMP of the same member): `review`, never choose automatically.

## 3. Transformations allowed without review

- Rename/organize; lossless format conversion; crop by existing metadata; build atlas/`SpriteFrames` from already-identified frames.

## Transformations that require a recorded decision (DEC or a note in the batch manifest)

- Color-key removal (transparency): **never global**; per batch, with explicit color and tolerance, before/after preview.
- Change pivot/registration, rescale, reorder frames, infer animation direction/duration.

## 4. Godot

- Project import presets (filter off for pixel art, `mipmaps` off) via `.import`/preset — not per sprite.
- Atlas/tileset generated by a reproducible script (`tools/`), with the command in the manifest.
- Do not copy the whole archive into `res://`; only the FEAT's batch.

## 5. Batch report

Template: `agents/templates/doc-recovery-report.md`. Includes counts (input, ok, rejected, review), previews (paths), and what was **not** verified.

## Rules

- Running the script twice must produce identical bytes (determinism) — verify by hash.
- No writes to originals; if the script needs write permission there, it is wrong.
- Provenance/usage license per batch in the manifest or the report; missing → `[BLOCKER]` for distribution, not for development.
