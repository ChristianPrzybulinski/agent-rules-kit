# skills/core/ — session discipline and reasoning

| Skill | Scope | When to use |
|---|---|---|
| `evidence` | evidence-based reasoning, >98% confidence, skepticism | evaluate a proposal, decide between alternatives |
| `sessions` | session hygiene — plan first, one outcome, long sessions | session start, topic change |
| `session-review` | end of session — summary + review of the session against the kit, one proposal with evidence | after the requested work is delivered, or when the user closes the session |
| `tokens` | two communication lenses (technical vs. people), governed docs | long responses, text for humans, compression |
