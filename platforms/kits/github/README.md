# kit github

CI, PR and label governance templates for GitHub Actions.

## How to use

| File | Destination in the project |
|---|---|
| `workflows/*.yml` | `.github/workflows/` |
| `PULL_REQUEST_TEMPLATE.md` | `.github/PULL_REQUEST_TEMPLATE.md` |
| `CODEOWNERS` | `.github/CODEOWNERS` (edit the user) |
| `dependabot.yml` | `.github/dependabot.yml` |
| `labels.json` | reference for `scripts/labels-sync.sh` |
| `scripts/labels-sync.sh` | run from anywhere inside the repo: `bash platforms/kits/github/scripts/labels-sync.sh` |

`ci-java.yml` and `ci-godot.yml` are **reusable** workflows (`on: workflow_call`): copy them to the project's `.github/workflows/` and call them from a thin project workflow:

```yaml
# .github/workflows/ci.yml
name: ci
on:
  pull_request:
  workflow_dispatch:
jobs:
  java:
    uses: ./.github/workflows/ci-java.yml
    secrets:
      NVD_API_KEY: ${{ secrets.NVD_API_KEY }}
  godot:
    uses: ./.github/workflows/ci-godot.yml
    # with:
    #   godot-version: '4.7.2'
    #   test-runner: 'gdunit4'   # or 'gut'
```

## Notes

- `ci-java.yml` assumes the Maven wrapper (`./mvnw`), JDK 25 Temurin and the `platforms/kits/java-maven/pom-parent.xml` gates (Spotless, JaCoCo, PITest). Its `changes` job skips build/tests on docs-only diffs and runs `dependency-check` only when build files change; the mojo is pinned (`dependency-check-maven:13.0.0`, supports `nvdApiKeyEnvironmentVariable`), `NVD_API_KEY` is a required secret, and the NVD data cache is saved even when the gate fails.
- `ci-godot.yml` runs in `barichello/godot-ci:<godot-version>`. The `test-runner` input selects `gdunit4` (default) or `gut`; a missing runner addon or zero test suites fails the build — tests are never silently skipped. Its `changes` job exposes `code`/`export` outputs so the caller can gate a manual export job (requires `export_presets.cfg` committed to the repo). LFS objects restore from a cache keyed on the LFS file list.
- `spec-lint.yml` validates `docs/spec/**` **without checking out the kit**: it uses the local copy in `.github/spec-lint/` (generated by `platforms/tools/sync-project.sh`; no token, no other repo).
- `gitleaks.yml` needs `fetch-depth: 0` to scan the whole PR diff.
