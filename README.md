# agent-rules-kit

A plugin-first source of always-on rules, triggered rules, skills, references and templates for Devin Cloud, Devin CLI/Desktop, Codex and Claude Code. Plugin content lives under [`plugins/`](plugins/) — one plugin, `core`, with shared manifests (KIT-047); tooling and documentation stay at repository root.

Version: [`VERSION`](VERSION) · History: [`CHANGELOG.md`](CHANGELOG.md) · Contributing: [`CONTRIBUTING.md`](CONTRIBUTING.md) · Security: [`SECURITY.md`](SECURITY.md)

## Layout

| Path | Purpose |
|---|---|
| [`plugins/core/`](plugins/core/INDEX.md) | the kit's only plugin: always-on rules (`AGENTS.md`), hook guard; Java, Godot, Python and spec path rules; `reviewer` and `researcher` profiles; session, parallelize, review, git, security, code standards, testing, investigate, Java 25/Spring, Godot 2D, asset import, Krita, Docker, persistence, architecture, protocol contracts, grilling, the `sdd-*` pipeline and journeys; project and spec templates |
| [`platforms/`](platforms/) | machine tools ([`tools/`](platforms/tools/README.md)), validators and schemas ([`ci/`](platforms/ci/README.md)), files projects copy ([`kits/`](platforms/kits/README.md)) |
| [`docs/`](docs/) | [`design.md`](docs/design.md) (principles and context costs), [`projects.md`](docs/projects.md) (what a consumer repository carries), [`features/`](docs/features/README.md) (KIT records) |
| `.devin-plugin/`, `.claude-plugin/`, `.agents/plugins/` | the content-free Devin meta-plugin, which requires `core`, and the Claude Code and Codex marketplace catalogs |
| [`.github/`](.github/README.md) | on-demand CI, release and security automation |

`plugins/core/INDEX.md` is generated from the plugin's files by `platforms/tools/gen_index.py`. `VERSION` is the single source of the kit version: `check_kit.py`, `bump_version.py` and `release.yml` read it.

## Bootstrap

```bash
git clone https://github.com/ChristianPrzybulinski/agent-rules-kit.git ~/.ai-kit && ~/.ai-kit/platforms/tools/bootstrap.sh
```

## How each agent loads the kit

| Agent | Always-on | Skills/rules | Refresh |
|---|---|---|---|
| Devin Cloud | required plugin `plugins/core/AGENTS.md` | `plugins/core/skills/` and `plugins/core/rules/` | fetches `main` per session |
| Devin CLI/Desktop | root meta-plugin requires `core` | the required `core` plugin | app startup; doctor updates stale SHA |
| Codex | `~/.codex/AGENTS.md` → `~/.ai-kit/plugins/core/AGENTS.md` | marketplace plugins plus temporary fallback symlinks | launchd every six hours |
| Claude Code | `~/.claude/CLAUDE.md` → `~/.ai-kit/plugins/core/AGENTS.md` | marketplace plugins; path rules from the repo's `.claude/rules/<plugin>-<rule>.md` and project skills vendored in `.claude/skills/` (both generated by `sync-project.sh`, skills with `--vendor-skills`); user-level `~/.claude/rules/<plugin>-*.md` symlinks only with `AI_KIT_USER_RULES=1` | launchd every six hours |

User-level rule symlinks are opt-in with `AI_KIT_USER_RULES=1` (a rule present in both `~/.claude/rules/` and the repo's `.claude/rules/` loads twice); repos carrying `.claude/rules` need nothing, and `doctor.sh` removes the old symlinks by default.

## Devin plugin

The existing repository source remains valid: the content-free root meta-plugin requires `core`, so installing the repo installs the full kit:

```bash
devin plugins install ChristianPrzybulinski/agent-rules-kit               # core
devin plugins install ChristianPrzybulinski/agent-rules-kit#plugins/core  # the same plugin by path
```

Existing Customize entries need no source change; Reindex to pick up the new layout, and remove a `#plugins/dev` or `#plugins/sdd` entry, whose path no longer exists (KIT-047). The legacy `ai-kit` plugin should be removed (`devin plugins remove ai-kit`) — its path no longer exists. Run `devin plugins update` to force a local refresh.

## Codex

Bootstrap registers the marketplace and every plugin:

```bash
codex plugin marketplace add ChristianPrzybulinski/agent-rules-kit --ref main
codex plugin add core@ai-kit   # repeat per plugin, or let bootstrap/doctor iterate them
```

The root marketplace catalog lists `core`; `~/.codex/AGENTS.md` links to `~/.ai-kit/plugins/core/AGENTS.md`. While [openai/codex#22078](https://github.com/openai/codex/issues/22078) remains open, doctor maintains fallback skill symlinks to `~/.ai-kit/plugins/*/skills/` and removes them once plugin skills are exposed. Codex keeps entries for retired plugin names (KIT-038, and `dev` and `sdd` since KIT-047) in `~/.codex/config.toml`; remove each with `codex plugin remove <name>@ai-kit`.

`bootstrap.sh`, `refresh.sh` and `doctor.sh` find the Codex CLI through `platforms/tools/codex-bin.sh`: `$CODEX_BIN` when set, then `codex` on `PATH`, then the CLI bundled in ChatGPT.app or Codex.app, then `~/.cache/codex-runtimes`. A `CODEX_BIN` that is not executable is reported and no other CLI is used. Run `platforms/tools/codex-bin.sh` to see which CLI the kit uses.

## Claude Code

```bash
claude plugin marketplace add ChristianPrzybulinski/agent-rules-kit
claude plugin install core@ai-kit
~/.ai-kit/platforms/tools/bootstrap.sh
```

Bootstrap links the shared AGENTS file to `~/.claude/CLAUDE.md`, links every plugin path rule under `~/.claude/rules/<plugin>-<rule>.md`, and narrows Devin imports so the same Claude file is not loaded twice. The marketplace `renames` map migrates installed retired names (`ai-kit`, the fourteen pre-KIT-038 plugins, and `dev` and `sdd` since KIT-047) to `core`, and `forceRemoveDeletedPlugins` uninstalls the ones mapped to `null`; a renamed plugin loads after one `claude plugin install <name>@ai-kit`, which `refresh.sh` and `doctor.sh` run.

Every repository enables only `core@ai-kit` in `.claude/settings.json` (the guard hook lives in the plugin only). A repository that vendors its skills (`sync-project.sh --vendor-skills`) loads its profile's skills twice on a machine with the plugin (`/core:name` and `/name`); prefer the vendored copy, because it is the only form that reaches Claude Code cloud sessions, the GitHub Action and Devin Cloud.

## Refresh and diagnosis

On macOS, launchd runs `platforms/tools/refresh.sh` at login and every six hours. `platforms/tools/doctor.sh` repairs clone, plugin and symlink state, warns when a Claude plugin cache differs from the kit (`refresh.sh` reinstalls it, KIT-013), and sets Claude Code's `autoCompactWindow` to `200k` when `~/.claude/settings.json` has none (KIT-010). Nothing refreshes at agent session start.
